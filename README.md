# SA 환각 감정소

2026-11-10에 사용자가 제공한 오르서버 펫정보 HTML 357개 항목과 기존 공개 자료·클라이언트 보충 자료를 합친 370개 항목(288종)의 계산기입니다. 목록에는 같은 이름을 한 번만 표시하고, 상세 화면의 일반·환생·진화 탭으로 형태를 선택합니다. 형태별 원본 ID와 성장률·초기치·획득 방법·탑승 여부·이미지를 보존하며, 능력치 입력란 이름 옆에 선택한 형태의 S급 참고 초기치를 표시합니다.

## 핵심 교정

- 표시 초기치 판정을 부동소수점식 대신 정확한 정수 분자식으로 처리
- 성장률 역산 신뢰도가 낮은 베로포리를 근사 데이터로 표시
- 카타르카스의 이론 S급 참고 초기치가 실제 정수 배분으로 불가능함을 안내
- 검색, 속성 필터, 상세 조합, 성장률 범위 기능 유지

## 생성

```powershell
node scripts/build-site.mjs
node scripts/verify-site.mjs
node scripts/verify-variants.mjs
```

원본 공개 사이트 구조가 바뀌면 생성 과정이 조용히 잘못되지 않고 오류와 함께 중단됩니다.
